# Bartrmp

## Project Overview

Bartrmp is a full-stack web application developed as a mini project submission.  
The project is designed to provide a modern and interactive platform with both frontend and backend integration. It demonstrates the implementation of responsive user interfaces, API handling, database connectivity, and complete client-server architecture using modern web technologies.

The project focuses on delivering a smooth user experience along with scalable backend functionality.

---

# Objectives

- To develop a complete full-stack web application
- To understand frontend and backend integration
- To implement responsive UI design
- To perform CRUD operations using APIs
- To deploy and manage a production-ready project

# Installation and Execution Steps

## Step 1: Clone the Repository

```bash
git clone https://github.com/mahakpatidar159/bartrmp.git
```

---

## Step 2: Navigate to Project Directory

```bash
cd bartrmp
```

---

# Frontend Setup

## Step 3: Open Frontend Folder

```bash
cd frontend
```

## Step 4: Install Dependencies

```bash
npm install
```

## Step 5: Run Frontend

```bash
npm start
```

Frontend will run on:

```bash
http://localhost:3000
```

---

# Backend Setup

## Step 6: Open Backend Folder

```bash
cd backend
```

## Step 7: Install Dependencies

```bash
npm install
```

## Step 8: Start Backend Server

```bash
node server.js
```

Backend server will run on:

```bash
http://localhost:5000
```
